## 1 安装

本文档介绍配套于《深入理解计算机系统》第三版第 4 章 Y86-64 处理器体系结构的处理器模拟器。模拟器代码以名为 `sim.tar` 的 tar 文件分发，可从 CS:APP3e 网站（csapp.cs.cmu.edu）获取。

将 tar 文件放在希望安装代码的目录中，然后执行：

```sh
tar xf sim.tar
cd sim
make clean
make
```

默认情况下，这会生成需要 Tcl/Tk 的图形界面版本。如果系统没有安装 Tcl/Tk，可以安装只输出 ASCII 文本的 TTY 版本。如何生成 GUI 和 TTY 版本，请参阅 `README`。

`sim` 目录包含以下子目录：

* `misc`：YAS、YIS 等工具的源代码，以及所有处理器模拟器共用的 `isa.c`。
* `seq`：SEQ 和 SEQ+ 模拟器的源代码，包含教材习题 4.52 所需的 HCL 文件。不同版本的构建方式见其中的 `README`。
* `pipe`：PIPE 模拟器的源代码，包含教材习题 4.54–4.58 所需的 HCL 文件。不同版本的构建方式见其中的 `README`。
* `y86-code`：本章许多示例程序的 Y86-64 汇编代码。可以自动测试修改后的模拟器，运行示例程序 `asum.ys`。
* `ptest`：针对不同指令、跳转情况和冒险情况生成系统化回归测试的脚本。这些脚本非常适合发现作业解答中的错误。

## 示例对象代码

以下是 `y86-code` 子目录中的 `asum.yo` 示例：

```text
# 从地址 0 开始执行
0x000: .pos 0
0x000: 30f40002000000000000  irmovq stack, %rsp  # 设置栈指针
0x00a: 803800000000000000    call main          # 执行 main
0x013: 00                     halt               # 终止程序

# 4 元素数组
0x018: .align 8
0x018: 0d000d000d000000      array: .quad 0x000d000d000d
0x020: c000c000c0000000             .quad 0x00c000c000c0
0x028: 000b000b000b0000             .quad 0x0b000b000b00
0x030: 00a000a000a00000             .quad 0xa000a000a000

0x038: 30f71800000000000000  main: irmovq array,%rdi
0x042: 30f60400000000000000        irmovq $4,%rsi
0x04c: 805600000000000000          call sum          # sum(array, 4)
0x055: 90                            ret

# long sum(long *start, long count)
# start 位于 %rdi，count 位于 %rsi
0x056: 30f80800000000000000  sum: irmovq $8,%r8    # 常量 8
0x060: 30f90100000000000000       irmovq $1,%r9     # 常量 1
0x06a: 6300                         xorq %rax,%rax   # sum = 0
0x06c: 6266                         andq %rsi,%rsi   # 设置条件码
0x06e: 708700000000000000           jmp test         # 跳转到 test
0x077: 50a70000000000000000 loop: mrmovq (%rdi),%r10 # 读取 *start
0x081: 60a0                         addq %r10,%rax   # 加到 sum
0x083: 6087                         addq %r8,%rdi    # start++
0x085: 6196                         subq %r9,%rsi    # count--，设置条件码
0x087: 747700000000000000 test: jne loop           # 为 0 时停止
0x090: 90                         ret               # 返回

# 栈从这里开始，并向较低地址增长
0x200: .pos 0x200
0x200: stack:
```

## 2 工具程序

安装完成后，`misc` 目录中有两个常用程序。

### YAS

YAS 是 Y86-64 汇编器。它接受扩展名为 `.ys` 的 Y86-64 汇编源文件，并生成扩展名为 `.yo` 的文件。生成文件包含 ASCII 格式的目标代码。最简单的使用方式是在 `y86-code` 目录中对 `asum.ys` 执行：

```sh
make asum.yo
```

### YIS

YIS 是 Y86-64 指令模拟器，按照指令集定义执行机器级程序。在 `y86-code` 目录中运行 `asum.yo`：

```sh
../misc/yis asum.yo
```

YIS 会执行程序，然后将寄存器和内存的变化打印到终端，格式如教材第 4.1 节所述。

## 3 处理器模拟器

三种处理器分别有以下模拟器：

* `SSIM`：SEQ 模拟器；
* `SSIM+`：SEQ+ 模拟器；
* `PSIM`：PIPE 模拟器。

每种模拟器都支持 TTY 和 GUI 模式。

**TTY 模式**：最简洁的终端界面，将输出打印到终端。不便于调试，但可安装在任何能够输出 ASCII 文本的系统上，并适用于自动化测试。

**GUI 模式**：图形界面，后文介绍。非常适合观察处理器的活动，但需要安装 Tcl/Tk。使用命令行选项 `-g` 启动。GUI 模式只能从对应模拟器所在的目录（`pipe` 或 `seq`）运行。

### 3.1 命令行选项

所有三种模拟器都支持以下选项：

* `-h`：打印命令行选项摘要。
* `-g`：使用 GUI 模式运行（默认是 TTY 模式）。
* `-t`：仅限 TTY 模式，同时运行处理器和 ISA 模拟器并比较结果。如果寄存器文件、内存和条件码没有差异，会输出 `ISA Check Succeeds.`。
* `-l m`：仅限 TTY 模式，最多执行 `m` 条指令后停止；默认上限为 10000 条。
* `-v n`：仅限 TTY 模式，将详细程度设置为 `n`，范围为 0 到 2，默认值为 2。

GUI 模式必须在命令行中指定对象文件名；TTY 模式下对象文件名可选，默认从标准输入读取。

在 `seq` 目录中的典型用法：

```sh
./ssim -h
./ssim+ -t < ../y86-code/asum.yo
./ssim -g ../y86-code/asum.yo
```

第二条命令也适用于 PIPE 模拟器 `PSIM`，只需从 `pipe` 目录运行。

### 3.2 SEQ 模拟器的 GUI 版本

在 `seq` 目录中执行以下命令启动 GUI 版本：

```sh
./ssim -g ../y86-code/asum.yo &
```

末尾的 `&` 允许模拟器在后台运行。程序会启动三个窗口。

主控制窗口包含：

* **控制区**：`Quit`、`Go`、`Stop`、`Step` 和 `Reset` 按钮。`Quit` 退出；`Go` 开始运行；`Stop` 暂停；`Step` 执行一条指令后暂停；`Reset` 将处理器恢复到初始状态。
* **模拟器速度**：滑块向右移动会提高运行速度。
* **处理器状态**：显示当前各处理阶段的信号，基本对应教材图 4.23。指令显示名称而非数字 `icode` 和 `ifun`；寄存器显示名称，`----` 表示不需要寄存器访问。
* **寄存器文件**：显示 15 个程序寄存器。最近更新的寄存器以浅蓝色高亮。寄存器第一次被设置为非零值之前不会显示其内容。
* **状态**：`AOK` 表示没有问题；`ADR` 表示读取指令或访问数据时发生寻址错误；`INS` 表示遇到非法指令；`HLT` 表示遇到 halt。
* **条件码**：显示 `ZF`、`SF` 和 `OF`。

注意：寄存器写入要到下一个时钟周期开始时才真正更新，因此通常需要再执行一步才能看到变化。条件码也是如此。

示例界面展示的是 `asum.ys` 第 29 行第一次执行时的状态。PC 为 `0x085`，程序已经处理了 `addq %r8, %rdi`，`%rax` 保存第一个数组元素的和，`%rsi` 保存即将减一的 4，`%rdi` 保存第二个数组元素地址。对 `%rsi` 的写回值 3 尚未在当前周期写入。

程序代码窗口包含一个文件输入框和 `Load` 按钮。左侧显示对象代码，右侧显示汇编代码，中间的星号表示当前正在模拟的指令。修改文件名并点击 `Load` 可加载新的程序。

内存内容窗口只显示程序执行以来发生变化的地址范围。每行显示两个内存 words；左侧是根地址，右侧按地址低位分列。示例中的内存内容来自 `asum.ys` 的栈：初始化 `%rsp` 为 `0x200` 后，调用 `main` 将返回地址 `0x013` 写入 `0x01f8`；`main` 调用 `sum` 又将返回地址 `0x055` 写入 `0x01f0`。

### 3.3 PIPE 模拟器

PIPE 模拟器同样生成三个窗口。控制面板包含相同的控制按钮、寄存器文件、状态和条件码，并额外显示流水线寄存器以及性能监视器。性能监视器显示模拟周期数、已完成指令数和 CPI。

每个流水线寄存器显示两部分：上方白色区域是当前值，下方灰色区域是输入值。除非该流水线寄存器产生气泡或停顿，否则输入值会在下一个时钟周期装入寄存器。

SEQ 每次执行一步完成一条指令；PIPE 每次执行一步则为每个流水线阶段各推进一个周期，因此多个指令会同时处于不同阶段。

PIPE 的代码窗口使用 `F`、`D`、`E`、`M`、`W` 标记指令所处的取指、译码、执行、访存和写回阶段。

PIPE 中每个阶段都有状态字段 `Stat`：`AOK` 表示正常；`BUB` 表示此阶段是气泡；`ADR` 表示无效内存地址；`INS` 表示非法指令；`PIP` 表示流水线错误（例如某流水线寄存器同时要求停顿和气泡）；`HLT` 表示 halt。最后四种状态到达写回阶段后模拟器会停止。

运行 `asum.ys` 时，典型流水线状态如下：

* **写回**：初始测试中的 `jne` 即将完成。
* **访存**：`mrmovq` 从地址 `0x018` 读出数组第一个元素；地址在 M 寄存器的 `valE` 中，内存读出的值位于 W 寄存器输入的 `valM`。
* **执行**：由于 `mrmovq` 和随后 `addq` 之间存在 load-use 依赖，该阶段插入了一个气泡。
* **译码**：`addq` 读取 `%rax` 和 `%r10`，但转发逻辑使用刚从内存读出的 `valM` 作为新的 `valA`。
* **取指**：从地址 `0x083` 取出 `addq`，预测下一个 PC 为 `0x085`。

## 4 一些建议

* 熟悉模拟器的操作。先运行 `y86-code` 中的示例程序。重点观察数据转发、分支预测错误、load 互锁和 `ret` 等情况。
* 需要主动查找资料。观察数据转发尤其困难。流水线寄存器 E 中 `valA` 的可能来源有七个，`valB` 有六个。可以将 E 的输入与所有候选来源比较。

`valA` 的可能来源包括：

* `R[d_srcA]`：源寄存器由 E 寄存器输入的 `srcA` 指定；
* `D_valP`：D 寄存器中的值；
* `e_valE`：M 寄存器输入的 `valE`；
* `M_valE`：M 寄存器中的 `valE`；
* `m_valM`：W 寄存器输入的 `valM`；
* `W_valE`：W 寄存器中的 `valE`；
* `W_valM`：W 寄存器中的 `valM`。

* 不要覆盖自己的代码。由于代码和数据共享地址空间，程序很容易覆盖代码，从而在执行被覆盖代码时完全失控。栈必须设置在离代码足够远的位置。
* 避免使用过大的地址。模拟器不允许地址超过 `0x0FFF`；跨越很大地址范围修改内存也会使内存显示难以使用。

### GUI 模式的注意事项

* 必须从模拟器的工作目录执行程序：`ssim` 或 `ssim+` 要在 `seq` 目录中运行，`psim` 要在 `pipe` 目录中运行。这是 Tcl 查找模拟器配置文件方式导致的要求。
* 在 Unix 系统上使用 GUI 模式时，记得初始化 `DISPLAY`，例如：

```sh
setenv DISPLAY myhost.edu:0
```

* 某些 Unix X Window 管理器会让“Program Code”窗口以关闭的图标开始，需要手动展开。
* 某些 Microsoft Windows X Server 在内存内容变化后不会自动调整“Memory Contents”窗口大小，需要手动调整。
* 如果让 `psim` 或 `ssim` 执行无效的对象文件，模拟器会因 segmentation fault 终止。
